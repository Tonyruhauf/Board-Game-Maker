
-----| BoardGameMaker Guide|-----

--| Installation instructions
Drop the "BoardGameMaker" folder into your project.
Then, move the "script_templates" folder inside it into your root "res://" directory.

--| Creating a new game
Use the GameMaker scene to quickly create the game files.
Then, you can start coding your game inside of "main.gd".
If you create scripts, scene, resources, or any file, put them
inside the "Game" folder. Feel free to organise the "Game" folder as you wish.
